## 验证边界

- 当前机器没有 Docker Engine，未实际构建/运行 Linux Docker 镜像；Dockerfile 与 Compose 按同一 standalone 产物组织，但不能将 Node 运行验证表述为 Docker 实测。
- 尚未连接用户的国内服务器，未验证目标机器架构、镜像下载源、域名、证书、Nginx、安全组和不同运营商访问。
- 未做负载测试、多副本部署或复杂浏览器兼容性测试。
- 原生 Node 环境中，这版 SQLite API 仍有实验性标记，固定 Node 24 版本线并保留可替换的存储适配层。
